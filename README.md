## 1. Project Goal

Создать OBS-скрипт с голосовым ИИ-ассистентом, который общается со стримером, отвечает голосом, отображает эмоции через аватар и самостоятельно начинает разговор при необходимости.

## 2. Инструкция по запуску

1. Установить OBS Studio и Python.
2. Скачать проект.
3. Установить зависимости командой:

   ```bash
   pip install -r requirements.txt
   ```

4. Открыть OBS Studio.
5. Перейти в **Инструменты → Скрипты**.
6. Добавить основной скрипт проекта.
7. Указать API-ключ и выбрать ИИ-модель.
8. Настроить микрофон, голос и аватар.
9. Сохранить настройки и запустить ассистента.
